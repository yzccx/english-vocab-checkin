# 英语单词学习打卡（本地静态版）

一个零依赖、可在本地直接运行的英语背单词 + 打卡网页。界面简约，学习进度和打卡记录只保存在当前浏览器的 `localStorage` 中。

## 功能

- **三个内置词库**：考研必备（5044 词）、四级必备（4544 词）、六级必备（3991 词），去重后共 7174 词条。
- **逐词学习**：随机抽词 → 先回想 → 显示释义 → 标记“认识 / 模糊 / 再学”；认识过的词会从下轮自动移除。
- **短文学习**：内置按词库分类的 9 篇英文短文，正文高亮重点词，点击即看释义并计入当天学习；可在设置里添加自己的短文。
- **每日统计**：逐词与短文两种模式分别计数，同一天内同一单词只计一次。
- **打卡**：默认每天学满 20 词即可打卡（可在设置修改），显示本月日历、最近 30 天和连续打卡天数。
- **自定义单词 / 短文**：用于补充词库中缺少的词（例如常见基础词）。
- **数据备份**：支持一键导出 / 导入 JSON，防止换浏览器或清理缓存丢记录。

## 运行方式

**方式一（推荐）**：双击 `start.ps1`（需要电脑装有 Python），会自动启动本地服务并打开 `http://127.0.0.1:8123`。

**方式二**：在项目目录执行 `python -m http.server 8123`，然后浏览器打开 `http://127.0.0.1:8123`。

**方式三**：直接双击 `index.html`。多数情况下可正常使用；如果发现刷新后进度丢失，请改用方式一或方式二（浏览器对 `file://` 页面的本地存储支持有差异）。

## 用手机访问（同一 WiFi）

1. 电脑与手机连到同一个 WiFi。
2. 在电脑上运行 `start.ps1`，或执行 `python -m http.server 8123 --bind 0.0.0.0`。
3. 在手机浏览器地址栏输入电脑的局域网 IP 加端口，例如：`http://10.190.188.52:8123/`。
4. 如果手机打不开，通常是 Windows 防火墙拦住了 Python。可在“Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙”中允许 Python 访问**专用网络**，或临时关闭专用网络防火墙再试（建议用前一种）。

手机与电脑的学习记录是**独立存储**的：手机上学到的数据保存在手机浏览器里，不会自动同步回电脑；需要的话可以分别导出备份文件互相导入。

## 数据与隐私

- 内置词表在 `js/data/words.js`，由 `tools/build_words.py` 从开源词库生成；浏览器加载后无需联网。
- 学习记录、自定义内容与设置均保存在本机浏览器，不上传任何服务器。
- 建议在“设置 → 数据备份”中定期导出。
